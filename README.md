# Pharmacy Inventory & Sales Analysis

A comprehensive data analysis and inventory management project evaluating retail pharmacy operations, stockout risks, sales distribution, and profitability margins.

## 📊 Project Overview
Designed to optimize inventory tracking and monitor business performance using structured spreadsheet operations. This project simulates retail data for 500 transactions, translating raw logs into actionable business insights.

## 🔑 Key Business Insights & Metrics
- **Total Sales Revenue:** $22,880.27
- **Total Profit:** $8,518.56
- **Total Units Sold:** 6,216 units
- **Current Inventory Value:** $1,644.59
- **Inventory Risk Flag:** Successfully identified 13 medicines currently falling below the reorder threshold to prevent stockouts.

## 🛠️ Skills & Techniques Demonstrated
- **Data Organization & Cleaning:** Managed structured relational data across raw transaction logs and summary tabs.
- **Formulas & Functions:** Utilized logical statements, lookup functions, and aggregate calculations for cost and profit analysis.
- **Reporting & Dashboards:** Built dynamic pivot tables and a consolidated summary dashboard to highlight key performance indicators (KPIs) and category-wise revenue distribution.
